# Recurso auténtico de QA

`stone.png` es una copia sin transformación del recurso local
`~/DEV/GAMES/la-bahia/addons/psx_look/demo/art/stone.png`.
Se utiliza exclusivamente en el proyecto temporal de QA, mediante IndexedDB,
`assetImage`, un material vinculado y el compilador de Century.
Es una textura pixel art de 64 × 64; no representa una textura fotográfica ni un mapa normal.
No se instala en proyectos del usuario ni se distribuye al Player.
