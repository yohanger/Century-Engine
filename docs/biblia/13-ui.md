# Interfaces del juego y estilos

`src/engine/runtime/ui/manager.js` compila y administra documentos `.ui`; `sfc.js`, `design.js`, `design-html.js`, `design-script.js` y `components.js` distribuyen plantilla, diseño, script y controles. `UiRoot.vue` dibuja la UI durante gameplay. `theme.js` genera tokens `--rt-*`; no confundir la UI de juego con el tema editorial.

<pre>Recurso .ui → compileUi / compileScript → UiManager → UiRoot
                                       ← host / themeVars</pre>

## Cascada y propietarios

| Fuente | Ámbito |
| --- | --- |
| `src/styles.css` | Tokens globales, body, reglas compartidas |
| `src/App.vue` | Estilos locales y sobrescrituras de raíz editorial |
| `src/core/editor/theme.js` | Tema programático de editores CodeMirror |
| `src/filmmaker/film-ux.css` | Estilos de FilmMaker |
| `src/engine/runtime/ui/theme.js` | Tema de juego |
| Componentes Vue | Bloques scoped, reglas globales e inline |

Localizar el selector efectivo antes de cambiar un token. El inventario CSS enumera declaraciones, no la cascada computada. Los botones globales pueden afectar la alineación flex aunque exista `text-align`; corregir en el ámbito propietario cuando el efecto sea local.

**Impacto:** evaluar reglas de ámbito, estilos de popups, responsividad, estado de foco y temas de juego; validar en Electron, no solo con lectura del CSS.
